### Movement

| Key | Action |
| --- | ------ |
| WASD + mouse | Move and look |
| W, W | Sprint (double-tap) |
| Scroll | Held card distance |

### Cards

| Key | Action |
| --- | ------ |
| E / LMB | Grab — hold and release to throw |
| P / RMB | Pin — walls flatten, air pins float |
| F | Kick the cards ahead of you |
| O | Open the card's source page |
| Q | Cancel pinning |

### World

| Key | Action |
| --- | ------ |
| M | Tag museum on / off |
| G | Sweep cards into a wall grid |
| / | Type-to-search |
| MMB (hold) | Radial menu |
| Tab | Sort cards by date |
| N | Minimap |
| Ctrl+R | Reload cards from Supabase |
| PgUp / PgDn / Ins | Previous / next / new room |

### System

| Key | Action |
| --- | ------ |
| F1 | Settings |
| F2 | Tutorial |
| F3 | FX tuning |
| F4 | Rooms + PDF import |
| F6 | B-roll recorder |
| F12 | Screenshot to `Pictures\scrapworld` — Shift for 2x resolution |
| I | Import wizard |
| Esc | Pause menu and keymap |
